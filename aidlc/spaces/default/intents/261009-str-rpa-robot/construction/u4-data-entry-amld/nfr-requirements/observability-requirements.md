# Observability Requirements — U4 DataEntryAMLD

- **OBS-U4-1:** Log JSON (timestamp/level/message) ở các mốc: đăng nhập (số lần
  reload), nhập từng Phần (I/II/IV/V/VI), chặn tick ngoài tập, upload tài liệu,
  retry, kết quả.
- **OBS-U4-2:** Log đủ để U5 dựng trạng thái (mã lỗi, chi tiết); không log secret.
